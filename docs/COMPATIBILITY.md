# 兼容性与功能边界

本项目只面向 **Sony NEX-6（第一代 PMCA，固件 1.03，Android 2.3.7 / API 10）**。在取得该机型的实机证据前，下面所有“支持”都只表示代码按该平台设计，不表示已经验证。

## 1. 机型

| 机型 / 固件 | 状态 | 说明 |
| --- | --- | --- |
| **NEX-6，固件 1.03** | 开发目标，**未实机验证** | 本项目的构建、参数表和按键映射都按该平台设计 |
| NEX-6 其他固件 | 未评估 | 不能从 1.03 推定；CameraEx、参数 key 和扫描码都可能不同 |
| a5100 / ILCE-5100 | 不适用 | 请使用 a5100 版 Film Studio；本项目不修改 a5100 应用 |
| 其他 PMCA 机型 | 未评估 | 不承诺可用；不要仅因“也是索尼相机”就安装 |
| 不支持 PMCA 的机型 | 不支持 | 没有机内应用安装平台，无法安装 |

安装还需要：

- NEX-6 的「应用程序」入口已通过 `sony-nex6-app-menu-unlock` 流程恢复；
- 相机已启用 Wi-Fi ADB；
- APK 通过 ADB 安装，包名 `com.filmstudio.nex6`。

## 3. 画质与色彩边界

- 这是**参数级近似**。a5100 版的观感来自 3×3 颜色矩阵 + 1024 点 Gamma 曲线，NEX-6 固件没有这些接口。
- 17 个风格对应 `color-mode`、饱和、对比、锐度、A-B/G-M 微调和 DRO 的组合；白平衡一律 `auto`，不锁色温；不是 3D LUT。
- 风格名称只用于说明取向，不代表与富士、理光或徕卡官方色彩逐像素一致；两个徕卡 Look 只参考上游 a7R II 版的命名与参数取向。
- 黑白风格走双路径：ACROS 写 `color-mode=mono` + `picture-effect=richtone-mono`，HCBW/MORI 写 `mono` + `rough-mono`。照片效果开启时 Sony 会忽略创意风格及其滑块，因此黑白强度可能不再改变对比；两路都会回读并显示在右上角 `CM … FX …`，固件拒绝时记录 `MONO` / `DROPPED`。
- 强度 30/50/70% 对饱和、对比、锐度和微调做线性缩放；创意风格与 DRO 档位不插值。
- 某些机身可能丢弃微调或 DRO；应用会写 `DROPPED` 并退化到核心参数。
- NEX-6 这一代创意风格表没有 `neutral`（标准/生动/肖像/风景/黄昏/夜景/红叶/黑白/棕褐色）。0.2.19 起固件风格表可读且不含 neutral 时，七个中性底风格（CHROME/PRONEG/CNEG/ETERNA/BLEACH/GR-/LEICA-C）回退 `standard` 并按强度额外降饱和（clamp -3），日志 `STYLE neutral fallback standard sat=…`、右上角 `CM standard`；风格表不可读时照发 neutral 由回读决定。
- 实时取景与机内 JPEG 使用同一组运行时参数；不同机身的实际颜色可能不同。

## 4. 行为边界

- **模式拨盘必须在 P / A / S / M**。用户在 NEX-6 上确认（0.2.15）：iAuto 与 SCN 由相机接管创意风格和照片效果，黑白会出彩色，其他风格也可能被覆盖；拨到 P 后黑白正常。完整面板底部右侧的 `P/A/S/M:风格` 提示用于提醒这一点。这是用户口述观察，不是可读日志证据。
- **只在应用运行期间生效**。退出或暂停后恢复进入时的参数；原生相机不会保留风格。
- **仅静态照片**。PLAY、MOVIE 被忽略；DISP 用于打开/关闭屏内日志；没有录像菜单、格式或帧率控制。
- **不写设置存储**。没有把风格保存为相机预设的功能。
- **不修改固件**。不写 Backup 属性、不做工厂重置、不安装系统组件。
- **对焦框不是机身 AF 点**。NEX-6 的 CameraEx 不向第三方应用暴露真实 AF 坐标；框是应用自绘的居中指示，实际对焦区域由相机的「对焦区域」设置决定。
- **拍摄依赖相机原生保存**。应用调用 `takePicture(null,null,null)`，然后按文件名检查 `DCIM` 是否出现新 JPEG；不会读取照片内容。
- **日志尽力而为**。存储卡不可写或 FUSE 拒绝时可能没有日志；路径见 [ARCHITECTURE.md](ARCHITECTURE.md#9-日志与隐私)。

## 5. 安装风险

- 本项目是实验软件，不承诺“不炸机”“不会出问题”或“与 a5100 完全一致”。
- 实机测试前备份存储卡并保证电量充足。
- 不要用相机的「设置 → 初始化」排查问题；CN2 预设会重新关闭应用入口。
- 解锁参数仅适用于 NEX-6 1.03 / `CX76001_CN2`，不得套用到其他机型、固件或区域。
- 不要卸载 Sony 系统包。签名冲突时只卸载 `com.filmstudio.nex6`，或使用同一签名密钥重新构建。

## 6. 什么时候可以写“已验证”

至少需要：

1. 在目标 NEX-6 上安装、启动，取景和覆盖层持续显示；记录完整面板底部的 `P/A/S/M:风格` 提示；
2. **把模式拨盘置于 P / A / S / M**；iAuto / SCN 下相机接管风格，黑白出彩色属于预期行为；
3. 切换全部 17 个风格和 4 档强度，日志有对应 `APPLY`，并记录任何 `DROPPED`；ACROS/HCBW/MORI 还需记录 `CM … FX …` 并确认成片为灰阶；0.2.19 起记录启动 `CAP color-mode=…` 风格表，若不含 neutral 还需记录 `STYLE neutral fallback` 与 `CM standard`；
4. 中央键/快门实际产生 JPEG，`SAVED` 行给出文件名；
5. S1 对焦框出现并在合焦/失败时变绿/变红；
6. DELETE/SK2 三阶段可用；
7. 中文界面无豆腐块；
8. MENU/BACK 退出后原生取景恢复；
9. 退出应用后取回 `/sdcard/FSNEX6/REPORT.TXT`，其中包含 `START`、`BODY`、`OPEN`、`PREVIEW`、`APPLY`、`SHOOT`、`SAVED`、`RESTORE`、`EXPORT` 等记录。

只有完成这些并保存证据，才能把 `camera_tested` 改为 `true`。单项通过不等于全部兼容。
